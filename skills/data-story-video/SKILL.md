# 근거 기반 차트 영상

실제 자료를 하나의 흐름으로 설명하는 HIS01 방식의 제작법이다. 짧은 문구만 넘기는 영상보다 **실제 데이터가 움직이며 하나의 질문에 답하는 영상**을 만든다. 현재 요청이 이 기본값보다 우선한다.

## 구성과 설명

- 먼저 영상 전체가 답할 질문 하나를 정하고 관련 차트를 묶는다. 차트마다 무관한 개발 사건을 덧붙여 흐름을 끊지 않는다.
- 기본 흐름은 **질문 → 익숙한 예시·용어 풀이 → 실제 차트의 변화 → 기록에서 얻은 판단**이다. 예시는 이해를 위한 비유임을 표시하고 실제 사용자 경험으로 꾸미지 않는다.
- AI에 관심 없는 사람도 축·범례·단위·변화를 읽게 설명한다. 기술 용어와 원래 수치, 조건, 한계는 유지한다. 쉬운 설명에 시간이 더 필요하면 장면을 늘리며, 핵심 정보를 삭제하거나 전체를 무작정 2배속하지 않는다.
- 각 차트 아래에 현재 무엇을 보고 있는지와 왜 의미가 있는지 1–2줄씩 넣는다. 같은 화면에서도 설명을 순차적으로 바꾸되, 읽을 시간을 준다.
- 기본은 무음이다. 현 도식·차트의 설명을 개선하며, 실제 제품 화면은 요청이 있을 때 사용한다.
- LinkedIn은 구현·설계 판단·검증 한계까지 다루는 별도 기술 문서 초안을 작성한다. Instagram은 같은 자료를 쓰더라도 질문과 리듬을 별도 설계한다.

HIS01 방식의 시간 구성·색·차트 순서와 독립 제작 예제는 [references/his01.md](references/his01.md)를 읽는다. 고정 규격이 아니라 재현 가능한 출발점이다.

## 제작 전 레퍼런스 리서치

새 주제·새 편·대규모 재편집에서는 대본 전에 **대상 채널의 최근 관심 주제와 실제 영상·이미지 표현**을 조사한다. 최근 논점을 본인의 기록과 연결할 수 있는지 먼저 판단하고, 채택한 표현을 장면에 연결한다. 기존 HIS01의 장점을 기준으로 필요한 부분을 개선한다.

기간·작성자·원문 URL·실제 확인한 영상 구간·확인 한계를 남긴다. 외부의 관심사를 본인의 개발 사실이나 성과로 바꾸지 않는다. 구체적인 조사·선정·저장 방식은 [references/preproduction-research.md](references/preproduction-research.md)를 따른다. 단순 색상·오탈자 수정은 기존 리서치를 재사용한다.

## 근거부터 제작하기

1. 사전 리서치의 후보 주제를 본인 자료에 대조한 뒤, 원천 문서·로그·커밋·CSV를 읽고 각 주장에 출처와 관찰 기간, 집계 단위, 계산식, 제외 범위를 붙인다. 실제 경험, 문서의 관찰, 현재 해석, 추정값을 구분한다.
2. 장면별로 시간, 화면 변화, 하단 설명, 연결된 근거, 전달할 인사이트를 작성한다. 기술 사례는 요구 → 구현 선택 → 검증 → 남은 한계가 확인되는 범위에서 연결한다.
3. Motion Canvas의 데이터 기반 장면을 우선 재사용하거나 작성한다. 날짜·순위·연결·면적의 변화가 주인공이 되게 한다. 수치를 장식용으로 만들지 않는다.
4. 해당 차트와 문구로 실제 MP4를 렌더한다. 실행 가능한 합성 데이터 차트와 텍스트·합성 코드는 `assets/his01-starter/`에 있다. 새 차트의 위치·범례가 다르면 crop과 overlay를 먼저 조정한다. 실행과 입력 계약은 [references/rendering.md](references/rendering.md)를 읽는다.
5. 데이터 대조, 전체 디코드, 길이·해상도·fps·무음 여부, 대표 프레임을 확인한다. 원본 근거까지 되짚어 보고 오해할 수 있는 문구를 고친다. 수행한 검증만 기록한다.

집계 해석의 자주 틀리는 경계: 코드량 ≠ 품질·생산성, 테스트 줄 비중 ≠ 커버리지, 커밋 시각 ≠ 근무 시간, 세션 수 ≠ 사람 수·동시 작업 수, 리뷰 지적 수 ≠ 고유 결함 수. 토큰의 API 단가 환산·추정 비용은 실제 청구액과 구분한다. 보간된 움직임은 새로운 실측값이 아니다. 해당 주제에 필요한 경계를 설명에 넣는다.

## 편별 납품

`ID - 제목/` 아래 `01-영상/`, `02-제작소스/`, `03-원고/`, `04-근거/`, `05-검증/`으로 모은다. 영상·표지, 의존성과 실행 방법이 명확한 소스, 장면 스크립트·자막·기술 설명 초안, 원천 집계와 계산 방법, 실제 검증 결과를 포함한다.

`ID.md` 하나에도 사전 리서치의 관련 관찰·레퍼런스 출처·적용 이유와 대본·설명·관련 근거 본문·계산식·수치 표·검증 결과를 모두 담는다. MD만 복사해 읽어도 의미와 근거를 이해할 수 있게 하고, 핵심을 외부 링크로 대신하지 않는다. 동영상 바이너리나 전체 제품 코드는 MD에 넣을 필요가 없다. 비공개 원천을 공개용 패키지에 넣을 때는 게시 범위를 따로 구분한다.
