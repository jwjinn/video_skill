# DEMO · 코드·시험·문서는 어떤 순서로 쌓였을까?

이 문서는 동봉 예제의 대본·원천 데이터·해석·검증을 모은 독립 문서입니다. 모든 수치는 합성 데이터이며 실제 프로젝트의 개발 이력이 아닙니다.

## 영상 스크립트

|시간|화면|표현|
|---|---|---|
|0–3초|도입|코드·시험·문서는 어떤 순서로 쌓였을까?|
|3–8초|익숙한 예시|서로 다른 재료가 쌓이는 순서를 보는 것과 같습니다. 코드베이스는 코드·시험·문서 등 제품의 재료 묶음입니다.|
|8–14초|주별 면적 차트 전반|구현·시험·문서의 줄 수를 같은 주별 기준으로 나란히 봅니다.|
|14–20초|주별 면적 차트 후반|재료가 늘어난 양을 보여 주며 품질이나 생산성 점수를 뜻하지는 않습니다.|
|20–25초|결말|재료의 양과 제품의 가치는 다릅니다. 이 예제는 차트 읽기와 제작법을 보여 주며 실제 프로젝트의 성과를 주장하지 않습니다.|

## 원천 표와 계산

출처: 동봉 motion-canvas/data/sample.csv. 단위는 가상 주별 코드 줄 수이며 결측값은 없습니다. 실제 측정이나 커밋 분석으로 얻은 값이 아닙니다.

|가상 주 시작일|구현|시험|문서|합계|
|---|---:|---:|---:|---:|
|2026-01-05|1200|100|200|1500|
|2026-01-12|2400|500|450|3350|
|2026-01-19|3000|1100|650|4750|
|2026-01-26|3900|1700|900|6500|

합계 = 구현 + 시험 + 문서 줄 수. 마지막 표본은 3,900 + 1,700 + 900 = 6,500줄입니다. 축의 최대값은 1,000 단위 올림으로 7,000입니다. 표본 사이의 부드러운 면적 이동은 시각적 보간이며 추가 실측값이 아닙니다. 상단 합계·날짜는 직전에 도달한 주별 표본을 가리킵니다.

## 기술 설명 초안

하나의 질문을 먼저 제시하고, 익숙한 재료 비유로 코드베이스의 뜻을 설명한 뒤 주별 누적 면적 차트를 연결합니다. 차트는 Motion Canvas의 signal로 시간에 따라 표시하고, 표본의 날짜와 합계를 별도로 보여 줍니다. 구현·시험·문서는 동일한 줄 수 단위로 구분합니다.

장면 설명은 Pillow로 만든 텍스트 레이어이며 FFmpeg가 차트 클립과 합성합니다. 코드량을 품질·생산성으로 환산하거나 시험 줄 수를 테스트 커버리지라고 부르지 않습니다. 이 구분은 새로운 자료를 적용할 때도 유지해야 합니다.

## 실행 검증

- Motion Canvas TypeScript 검사 및 실제 차트 MP4 렌더 통과.
- Python 합성, 최종 MP4 전체 디코드 통과.
- 1080×1350, 30fps, 750프레임, 25초, 무음.
- 도입·예시·차트 중간·끝·결말 프레임의 배치 확인.
- Codex marketplace의 플러그인 발견 및 버전 0.1.0 인식 확인.
- macOS에서 실행했습니다. Linux CI 결과는 저장소 Actions에서 별도 확인하며, Windows 전체 파이프라인은 검증하지 않았습니다.
- 위 검증은 렌더·배포 구조 검증이며 역사적 사실의 검증이 아닙니다.
